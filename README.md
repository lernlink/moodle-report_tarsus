# report_tarsus

Course report plugin for the Tarsus ↔ Moodle integration (Lerncoach).

Teacher analytics. Phase 1 builds on native Moodle data
(attempts / answers / usage ledger); Tarsus Advisory endpoints and
dropout-risk land later. CSV / Excel export.

- **Component:** `report_tarsus`
- **Target:** Moodle 5.2 · PHP 8.3
- **Status:** mock-first (Phase 1 = native-data placeholders)

See the project technical specification for full design details.
